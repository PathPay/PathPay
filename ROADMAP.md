# PathPay Roadmap

## Phase 1 – Payment Orchestrator (0–3 months)
- Collect user payment failure data (survey + manual)
- Build manual aggregation engine
- MVP: input merchant → recommended rail → aggregate success
- Demo: real failed checkout (laptop story)

## Phase 2 – Semi-Automated Execution (3–6 months)
- Integrate multiple crypto rails / stablecoin settlement
- Execute small test payments (sandbox)
- Track success rates & fees

## Phase 3 – Full Consumer Neobank (6–12 months)
- Stablecoin wallet + cards
- Automated routing engine with retries
- FX/fee optimization
- Mobile app for iOS/Android
- Regulatory compliance layer

## Phase 4 – Scaling
- Expand globally (Africa, Asia, LatAm)
- Add AI agent for automated checkout aggregation
- Partner with merchants for instant settlement
- Monetization: transaction fee, premium routing, card issuance
